# @ying-web/mid-autumn · 共望一轮月

一件可以互动的中秋网页作品，以月球、星空与思念为主角。

围绕三个层次展开：

1. **看见月亮** —— 进入页面即看到有月面细节、柔和月华的三维月球；
2. **等待中秋** —— 直接读懂距离中秋（农历八月十五）还有多久；
3. **留下思念** —— 给此刻想念的人，或未来的自己，留下一句话。

月亮承接望月与思念，含义通过构图、光影与文字自然表达。画面是艺术化的月夜，不按天文比例模拟地月运动。

## 节日倒计时（真实时间）

-   中秋之前：倒计时到当年中秋；
-   中秋当天：显示「今夕月圆」，以文案与氛围变化为主；
-   当天结束后：自动开始等待下一年。

所有日期按浏览器本地时区零点计算；倒计时使用真实时间，与场景动画互不影响。年历表覆盖 1900–2099 年，超出范围时界面会明确提示。

## 月夜场景

-   **月面**：LROC 色彩图与 LOLA 高程图用于月面着色和微小凹凸；相机取景保持稳定。
-   **旋转**：鼠标左键或手指从月球表面按下，向任意方向拖动即可连续旋转月球；手指离开月面后仍能继续拖动，松开停止。旋转姿态在每帧平滑追随指针，避免触摸采样造成卡顿；拖动时背景视差暂停。
-   **空间层次**：银河全景位于最远的球形穹顶；星点、淡雾和金尘分布在不同的三维深度，随指针产生克制的远近视差。相机和月球构图保持稳定。
-   **月光**：月球后方的三维球壳生成缓慢起伏的散射月华，两道宽而柔的光波向外传播；光强在球壳边界前渐隐，没有可见的硬边。
-   **星空与流星**：远近星点逐颗闪烁，近景金尘保持清晰。少量流星在不同空间深度快速掠过，亮头和细尾沿同一轨迹运动，可被月球遮挡。
-   **持续动画**：月球与银河的环境动画、背景月华和扩散波自动循环，打开留笺时也继续播放；无需手动开关。系统启用“减少动态效果”时自动关闭这些动效与流星，手动旋转仍可用。

## 留一句思念（留笺时间）

-   一个称呼字段（可不填）+ 120 字以内的留言，仅保存在当前浏览器的 `localStorage`；
-   明确提示「仅保存在此浏览器，不会发送给任何人」，不承诺跨设备同步或永久保存；
-   保存后可在页面查看、修改与删除；存储失败会明确提示；用户文本以普通文本渲染，不做 HTML 解析；
-   不收集姓名、邮箱或地理位置，不预置任何假留言。

## 技术栈

React 18 · TypeScript · Vite 5 · Three.js / @react-three/fiber / @react-three/postprocessing · 原生 CSS。

本地贴图：月面颜色 / 高程（NASA LRO/LROC、LOLA）与 ESO 全天银河全景，均随项目存放，无外部素材依赖。

## 工程结构

-   `src/utils/lunar.ts`、`src/utils/festival.ts`：农历换算与节日状态（纯函数）；
-   `src/hooks/useMidAutumn.ts`、`useNow.ts`：真实时间与节日信息；
-   `src/three/Moon.tsx`：月面着色、命中检测与平滑旋转；
-   `src/three/Starfield.tsx`、`Nebula.tsx`、`SpaceDepth.tsx`：远近星点、体积淡雾、金尘和银河；
-   `src/three/MoonAtmosphere.tsx`、`ShootingStars.tsx`：三维月华光波与不同深度的流星；
-   `src/three/sceneState.ts`、`useScenePointer.ts`：共享指针位置与视差状态；
-   `src/styles/global.css`：文字层、响应式排版与无 WebGL 兜底；
-   `src/notes/*`：留笺存储与面板；
-   `src/App.tsx`：信息层排版与整体组装。

每帧运动只更新 ref / 场景对象，不触发整页重渲染。

```bash
pnpm install

pnpm --filter @ying-web/mid-autumn build

node --experimental-strip-types scripts/verify-lunar.ts   # 农历日期与历年中秋
node --experimental-strip-types scripts/verify-core.ts    # 节日边界
```

### 时间调试（仅开发环境）

开发模式下右下角有一个可拖动的悬浮球，点击展开后可把当前时间**冻结到任意时刻**（中秋当天 00:00 / 12:00、前一天、跨年等明年、2099 后年历不支持，或自定义时刻），用来预览不同状态的界面，无需改动系统时间；一键即可恢复真实时间。该工具仅 `import.meta.env.DEV` 下挂载，生产构建会连同界面与样式一起剔除。

### 降级

-   无 WebGL 时显示 CSS 星空兜底，倒计时与留笺照常可用；
-   `prefers-reduced-motion` 下关闭自动环境动效、波纹和流星，保留主动拖动月球；
-   移动端信息区与场景分区排版，倒计时不被天体遮挡，留笺以底部抽屉展示。
